# Playwright E2E Tests

End-to-end browser tests for the Sauce Demo shopping application, built with JavaScript and Playwright Test. The suite exercises login, product inventory, sorting, cart actions, and the checkout flow.

## Requirements

- Node.js (LTS recommended) and npm
- A Sauce Demo instance or compatible application URL

## Setup

1. Install the project dependencies:

   ```bash
   npm install
   ```

2. Install the Chromium browser used by the test configuration:

   ```bash
   npx playwright install chromium
   ```

3. Create a `.env` file in the project root and set the application URL:

   ```env
   BASE_URL=https://www.saucedemo.com/
   ```

   The test configuration loads this value from the environment. Keep local environment files out of version control.

## Run the tests

Run the complete suite:

```bash
npx playwright test
```

Run a specific test file:

```bash
npx playwright test tests/test.spec.js
npx playwright test tests/inventory.spec.js
npx playwright test tests/cart.spec.js
```

Run tests with the browser visible:

```bash
npx playwright test --headed
```

Open the HTML report generated by the latest run:

```bash
npx playwright show-report
```

## Test coverage

- Valid user login
- Inventory sorting and cart badge updates
- Cart contents and removing products
- Checkout details, totals, and order completion

## Project structure

```text
├── data/                 # Test users and application text, URLs, and values
├── pages/                # Page objects for login, inventory, and cart workflows
├── tests/                # Playwright test specifications
├── playwright.config.js  # Test runner, browser, reporter, and base URL settings
└── package.json          # Project dependencies
```

## Configuration notes

The Playwright configuration currently runs tests in Chromium and writes an HTML report. Screenshots are captured on failure, and traces and videos are retained according to the retry/failure settings in `playwright.config.js`.
